git init. -->  cria um repo git na pasta atual
git status -->  mostra o status do trabalho (de cada arquivo)
git add nome arquivo --> adiciona arquivo para ser comitado
git commit -m "msg" --> faz commit fo que esrava para ser commitado
git log -->  mostra todos o historico de commit

## FLUXXO DE TRABALHO 

1. criar o diretorio do projeto
2. iniciar o git --?  git init.
3. edita ou cria arquivos
4. git status
5. git add <nome arquivo>
6. git commit -m "texto do commit"
7. git status
8. volta para o passo 3
